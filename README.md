# NEET.info private RAG assistant

A counselling Q&A assistant for **NEET.info** that runs entirely on one machine. It
answers from shipped cut-off, seat-matrix, fee and handbook data, cites the exact
row or section it used, and says **"Not in the sources"** when the data does not
support an answer. It also includes **Track A**, a college-option finder that lists
plausible colleges for a rank, category and state, with the source rows behind each
option.

- **Core task:** private, locally hosted RAG with citations and refusals (`neetrag/assistant.py`)
- **Track A:** NEET.info college predictor / counselling assistant (`neetrag/predictor.py`)
- **Model:** `qwen2.5:7b-instruct` (Q4_K_M, Apache-2.0) served by Ollama; embeddings
  `nomic-embed-text` (Apache-2.0). Both are open-weight and run locally. No cloud API is used.
- **Data:** synthetic only (fictional colleges, generated by `scripts/make_synthetic_data.py`).
- **Design note:** [docs/design_note.md](docs/design_note.md) (two-page PDF: [docs/design_note.pdf](docs/design_note.pdf))
- **Evaluation:** [eval/results.md](eval/results.md) and [eval/results_holdout.md](eval/results_holdout.md)

## Quick start (Linux, native)

Needs Python 3.10+, an NVIDIA driver and [Ollama](https://ollama.com/download/linux).

```bash
git clone https://github.com/DevAtomicRelease/CGPRR-AI-Developer-assignment.git && cd CGPRR-AI-Developer-assignment
```

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

```bash
ollama pull qwen2.5:7b-instruct
```

```bash
ollama pull nomic-embed-text
```

```bash
python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt
```

The repository ships a ready index in `index/`. To rebuild it from `data/` (about 35 seconds on the laptop GPU):

```bash
python -m neetrag build-index
```

Ask a question that is in the sources (cited answer):

```bash
python -m neetrag ask "What was the 2025 Round 2 AIQ GEN closing rank for MBBS at Ganga Valley Government Medical College?"
```

Ask one that is not (refusal):

```bash
python -m neetrag ask "What was the closing rank for MBBS at AIIMS Delhi in 2025?"
```

Track A, college options for a rank:

```bash
python -m neetrag predict --rank 12000 --category OBC --state "West Bengal"
```

Web UI and HTTP API on http://127.0.0.1:8080:

```bash
python -m neetrag serve
```

Run the evaluation and print the score table (writes `eval/results.md`, takes about a minute):

```bash
python eval/run_eval.py
```

```bash
python eval/run_eval.py --file eval/questions_holdout.jsonl
```

Unit tests for the deterministic parts (no GPU or model server needed) and lint:

```bash
pip install -r requirements-dev.txt && pytest && ruff check .
```


A citation such as `closing_ranks.csv#L437` means line 437 of `data/tables/closing_ranks.csv`;

## How it decides to answer or refuse

1. **Prompt-injection check.** Sentences such as "ignore the documents" or "tell me the
   cut-off is 1" are detected, logged to `logs/security.jsonl` and removed; only the rest of
   the question is answered.
2. **Questions with the user's own rank** go to the deterministic predictor. The language
   model never compares ranks (see the design note for why).
3. **Coverage rules:** a college that is not in the index, a year outside 2023-2025, or a topic
   the data does not cover (NRI quota, BAMS, mop-up rounds...) is refused before generation.
4. **Hybrid retrieval** (BM25 + dense embeddings, fused) with metadata filters from the
   question; a low best-match score is refused.
5. **The model must quote its evidence** word for word, then answer, then set a status.
6. **Post-checks:** each quote must really be in the source it names, and every number in the
   answer must appear in a cited source. Otherwise the answer is withheld.

## Evaluation summary

| Set | Questions | Pass | Should-refuse refused | Answerable wrongly refused |
|---|---|---|---|---|
| Development set (`eval/questions.jsonl`, used while building) | 20 | 20/20 | 8/8 | 0/12 |
| Held-out set, first and only blind run (`eval/results_holdout.md`) | 14 | 13/14 | 6/6 | 0/8 |
| Held-out set after fixing the one failure | 14 | 14/14 | 6/6 | 0/8 |
| Ablation: refusal questions with the rule layer switched off | 13 | 10/13 | 11/13 | - |
| Fresh-clone retest, then 5 repeat runs after the loop fix (dev ×3, held-out ×2) | 20 / 14 | all runs 100% | 8/8, 6/6 | 0/12, 0/8 |

The development score is optimistic because the system was tuned on it. The held-out failure
and the ablation are explained in the design note. Treat these as smoke tests on synthetic
data, not as a measure of real-world accuracy.

## Configuration

All settings are environment variables (see `neetrag/config.py`):

| Variable | Default | Purpose |
|---|---|---|
| `NEETRAG_CHAT_MODEL` | `qwen2.5:7b-instruct` | chat model name in Ollama |
| `NEETRAG_EMBED_MODEL` | `nomic-embed-text` | embedding model |
| `NEETRAG_LLM_BACKEND` | `ollama` | or `openai` for a local vLLM / llama.cpp server |
| `NEETRAG_EMBED_BACKEND` | `ollama` | keep embeddings on Ollama even when chat uses vLLM, or `openai` |
| `NEETRAG_OPENAI_URL` | `http://127.0.0.1:8000/v1` | local OpenAI-compatible endpoint |
| `OLLAMA_URL` | `http://127.0.0.1:11434` | Ollama endpoint |
| `NEETRAG_MAX_TOKENS` | `700` | hard cap on generated tokens |
| `NEETRAG_MIN_DENSE_SCORE` | `0.60` | refuse if the best dense match is below this |
| `NEETRAG_INDEX_DIR`, `NEETRAG_LOG_DIR`, `NEETRAG_DATA_DIR` | `index/`, `logs/`, `data/` | where things live |

On the RTX 6000 the same code can use a bigger model, for example
`NEETRAG_CHAT_MODEL=qwen2.5:32b-instruct` in Ollama, or vLLM serving
`Qwen/Qwen2.5-32B-Instruct-AWQ` with `NEETRAG_LLM_BACKEND=openai`. If you change the
embedding model you must rebuild the index.

## Known limits

- The data is synthetic and small (22 colleges, 2023-2025). Real counselling data has many more
  quotas, rounds and exceptions.
- The rule layer is pattern based. It catches the phrasings in the test sets but will miss some
  paraphrases (for example an unknown college typed in lower case without a known acronym), and
  the ablation shows the 7B model alone can then substitute a similar college.
- The 7B model occasionally falls into a repetition loop at the end of an answer. It is caught while streaming and the
  answer written before the loop is kept (flag `loop_truncated`); a loop anywhere else triggers one retry.
- Answers are in English only.
- The predictor bands (Likely / Borderline / Reach) are simple ratios to last year's closing rank,
  not a statistical model, and are labelled as such in every output.
